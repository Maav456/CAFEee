# ☕ CAFE – Modern Responsive Web Portal

## 📌 Overview

**CAFE** is a modern, fully responsive web portal designed for a café brand.
It features a clean layout, smooth scroll animations, mobile navigation support, and a creative glass-style container design.

The project focuses on:

* Responsive design
* Clean UI structure
* Modern CSS effects
* Mobile-first optimization
* Smooth user experience

---

## 🚀 Features

### 🎨 UI & Design

* Irregular glass-style container design
* Soft glow layered background effects
* Elegant typography (Playfair Display + Poppins)
* Smooth scroll reveal animations
* Modern café-themed color palette

### 📱 Responsiveness

* Fully compatible with:

  * Desktop
  * Laptop
  * Tablet
  * Android / Mobile devices
* Hamburger navigation for smaller screens
* Flexible grid layout for menu section
* No horizontal overflow

### ⚙️ Functionality

* Smooth scroll behavior
* Scroll-based animation reveal
* Toggle-based mobile navigation
* Semantic HTML structure
* SEO meta integration

---

## 🛠️ Technologies Used

* **HTML5** – Semantic and structured layout
* **CSS3** – Advanced styling and animations
* **JavaScript (Vanilla)** – Navigation toggle & scroll animations
* **Google Fonts** – Custom typography
